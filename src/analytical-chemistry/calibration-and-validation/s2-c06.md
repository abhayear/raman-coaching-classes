Try each problem first, then check the answer shown directly below.

**Problem 1 (Calibration and validation):** 25.0 mL unknown HCl titrated with 0.100 M NaOH; Veq = 20.0 mL. [HCl]?

**Answer:**

moles OH⁻ = 0.100 × 0.020 = 0.002 mol = moles HCl. [HCl] = 0.002/0.025 = **0.080 M**. Real life: same logic in water acidity testing.
