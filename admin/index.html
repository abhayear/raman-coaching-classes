Admin — document uploads

Upload syllabus, notices, forms, and papers. Students see new files on the Document Centre without redeploying the site.

One-time setup (Supabase)

Connect free cloud storage for admin uploads:

  1. Create a project at supabase.com
  2. Run supabase/schema.sql in the SQL Editor
  3. Create Storage bucket centre-documents (public read)
  4. Add Storage policies (see ADMIN.md)
  5. Create an admin user: Authentication → Users → Add user
  6. Copy Project URL + anon key into config/services.json
  7. Rebuild and push: python scripts/build_html.py
